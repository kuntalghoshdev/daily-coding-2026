# 📸 Photo Metadata Inspector

A Python CLI utility for inspecting image properties and EXIF metadata.

## ✨ Features

- Image dimensions
- Image format
- Color mode
- Megapixel calculation
- File size
- Camera make
- Camera model
- Lens information
- Date/time metadata
- ISO
- Aperture
- Shutter speed
- Focal length
- Flash information
- GPS metadata
- JSON report export
- EXIF metadata removal
- Creates a new cleaned image instead of modifying the original

## 🛠️ Technologies

- Python 3
- Pillow
- JSON
- pathlib
- datetime
