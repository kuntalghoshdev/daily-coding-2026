# 🧠 StudyPulse

A simple Python CLI application that analyzes a study session and calculates a productivity score.

## ✨ Features

- Enter study subject
- Track study time
- Track break time
- Track planned and completed tasks
- Calculate task completion percentage
- Calculate focus efficiency
- Calculate overall productivity score
- Give personalized study feedback
- Validate user input

## 📊 Productivity Formula

### Task Completion

Task Completion = (Completed Tasks / Planned Tasks) × 100

### Focus Efficiency

Focus Efficiency = Study Time / (Study Time + Break Time) × 100

### Productivity Score

Productivity Score =
(Task Completion × 0.60) + (Focus Efficiency × 0.40)

## 🛠️ Technology

- Python 3
- Command Line Interface
