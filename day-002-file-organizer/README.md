# 📁 Smart File Organizer

A Python command-line utility that automatically organizes messy folders based on file type.

## ✨ Features

- Organize files by category
- Preview organization before moving files
- Images
- Documents
- Spreadsheets
- Presentations
- Music
- Videos
- Archives
- Code
- Executables
- Unknown/other files
- Duplicate filename protection
- Organization statistics
- Undo the last organization
- Operation history stored in JSON
- Hidden files are ignored

## 📂 Categories

| Category | Examples |
|---|---|
| Images | JPG, PNG, GIF, WEBP |
| Documents | PDF, DOCX, TXT, MD |
| Spreadsheets | XLSX, CSV |
| Presentations | PPTX |
| Music | MP3, WAV, FLAC |
| Videos | MP4, MKV, AVI |
| Archives | ZIP, RAR, 7Z |
| Code | PY, JS, Java, C++, HTML, CSS |
| Executables | EXE, MSI, BAT |
| Other | Unknown file types |

## ▶️ Run

```bash
python file_organizer.py
